## 3. PR C：4 つのカテゴリーに分ける

### 3-1. カテゴリーの一覧

`src/subjects.js` に、カテゴリーの一覧を置く。スタート画面はこの一覧から作る。

```js
// スタート画面のカテゴリー（この順に並べる）
//   input：'noun'（番号を入れる）| 'cards'（カードから選ぶ）| 'url'（URL を入れる）
//   ready：false なら「準備中」と出すだけ
export const CATEGORIES = [
  { key: 'nouns', label: 'Nouns',        input: 'noun',  ready: true },
  { key: 'ninja', label: 'クリプト忍者', input: 'cards', ready: true },
  { key: 'cnp',   label: 'CNP',          input: 'cards', ready: true },
  { key: 'qr',    label: 'nanoQR',       input: 'url',   ready: false },
];
```

`PICTURES` の各行に `category` を足す：

```js
export const PICTURES = {
  'chibi-sakuya': { file: 'data/samples/chibi-sakuya.png', label: 'チビ咲耶', category: 'ninja' },
};
```

- 画像の置き場所（`data/samples/`）は変えない
- `category` は `CATEGORIES` の `input: 'cards'` のどれか

### 3-2. スタート画面

- 4 つのカテゴリーを、見出し（カテゴリー名）＋中身の形で上から並べる
  - **Nouns**：今の番号の欄そのまま
  - **クリプト忍者・CNP**：そのカテゴリーの絵のカード（今のチビ咲耶のボタンと同じ形：小さな画像＋名前、押すと `?pic=<名前>`）。**絵が 1 つもないカテゴリーは「準備中」と出す**（今は CNP がこれ）
  - **nanoQR**：「準備中」と、一言の説明（仮：「URL を入れると、QR コードをブロックで組み立てられます」）。入力欄はまだ置かない
- 説明文（`.lead`）を 4 つのカテゴリーに合う文にする（例：「遊びたい絵をえらぶと、40×40 のブロックパズルで遊べます。…」）
- スマホ縦で、Nouns の欄が最初の画面に入ること

### 3-3. 「別の Noun で遊ぶ」の言い方

チビ咲耶で遊んでいても「別の Noun で遊ぶ」と出ているので、**どの絵でも合う言い方**にする。

- 読み込み画面・完成画面のリンク「別の Noun で遊ぶ」→「**別の絵で遊ぶ**」
- 遊ぶ画面の左上 `naoblock` の title も同じ

### 3-4. 注意書き

- 今の「Nouns は CC0 です。…本アプリは非公式のファン作品です」は残す
- クリプト忍者・CNP の絵についての一言を足すかは**なおなおに確認**（5 章）。決まるまでは足さない

### 3-5. 検算

`tools/check.mjs --subjects` に足す：

- `PICTURES` の全部の絵に `category` があって、`CATEGORIES` の `input: 'cards'` のどれかになっている
- チビ咲耶は `ninja`
- `?pic=chibi-sakuya`・`?pic=1`・`?sample=1` が今までどおり `picture:chibi-sakuya`「チビ咲耶」（保存の名前・シェアの URL も前の版と同じ）
