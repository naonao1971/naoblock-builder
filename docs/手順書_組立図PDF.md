# naoblock builder 手順書（組立図の PDF 保存と、印刷の抜けを直す）

スマホのちーちゃん（実装）へ。MacBook のちーちゃん（検証）が下の「検証チェックリスト」で確かめるので、その前提で作ってください。
なおなおと 2026-10-15 に決めた内容です。決定事項は勝手に変えず、迷ったらなおなおに聞いてください。「（仮）」と書いたものは、なおなおに確認してから決めます。

※ v27（PR #27）のあとに始める。遊び方・パーツ割り・ステップの順番は変えません。変えるのは**印刷の中身と出し方だけ**です。

## 1. 何が起きているか（2026-10-15 Mac で調べた結果）

なおなおが iPhone の Chrome で Noun 222 を「組立図を印刷」→ PDF にしたもの（11 ページ）を、Mac で作った PDF と比べた。

| | iPhone（10/14 夜） | Mac の headless Chrome |
|---|---|---|
| ページ数 | 11 | 10 |
| ステップ | **1〜24 で終わり。25〜27 が抜けている** | 1〜27 すべて |
| 2 ページ目 | 表紙の注意書き 1 行だけ（はみ出し） | なし |
| 5 ページ目 | 買い物リストの残り数行だけ（はみ出し） | なし |

- アプリが作る中身は正しい。Mac で `buildPrintout` を呼ぶと、ステップの箱は 27 個そろっている。
- **抜けているのは、iPhone の印刷の段階**。iPhone は用紙の余白を自分で足すので、表紙と買い物リストがはみ出して 2 ページ増えた。そのぶん最後のページ（ステップ 25〜27）が出力されなかった、と見ている。
- 原因の決め手：`window.print()` を、`buildPrintout` で `<img>`（canvas の data URL）を 27 枚作った**直後**に呼んでいる。画像の読み込みを待っていないので、ページ数の見積もりと中身がずれやすい。
- つまり、ブラウザに「HTML をページに分けてもらう」やり方は、端末によって結果が変わる。

## 2. 作るもの

PR は 1 本（v28）。

1. **組立図の各ページを、アプリ自身が 1 枚の絵（A4 縦）として描く。** ページの分け方をブラウザにまかせない。
2. 完成画面のボタンを 2 つにする：
   - **「PDF で保存」**（新しく作る）：描いたページの絵を 1 つの PDF にまとめてダウンロードする。ファイル名は今の `fileName` に合わせて `Noun_222_naoblock.pdf` のようにする
   - **「プリンターで印刷」**（今の「組立図を印刷」）：同じページの絵を 1 ページに 1 枚ずつ並べて `window.print()`。**全部の画像の `decode()` を待ってから**呼ぶ
3. 図の見やすさを 3 か所直す（4 章）。

PDF もプリンターも**同じページの絵**から作るので、どちらで出しても中身は同じになる。

## 3. 決定事項

| 項目 | 決定 |
|---|---|
| ページの作り方 | **ページごとに canvas で描く**（A4 縦、横 1240 × 縦 1754 px くらい＝150dpi）。文字も canvas の `fillText` で描く（フォントは画面と同じ） |
| PDF の作り方 | ページの絵（JPEG、画質 0.9 くらい）を 1 ページに 1 枚入れた PDF を**自前で組み立てる**（PDF は JPEG をそのまま埋め込める。外部ライブラリは入れない） |
| PDF の文字 | 絵なので、文字は選んでコピーできない。それでよい（なおなお OK） |
| 保存のしかた | `<a download>` で Blob を保存。iPhone では PDF のプレビューが開き、共有ボタンから「ファイルに保存」できればよい |
| ページの順番 | 今と同じ：表紙 → 部品リスト・買い物リスト → 組立手順（1 ページに 4 ステップ） |
| はみ出し | 1 ページに入りきらないもの（買い物リストが長いときなど）は、**アプリが**次のページに送る。行の途中では切らない |
| 表紙の注意書き | 表紙の中に必ず入れる（表紙の絵を少し小さくしてよい） |
| 余白 | ページの絵の中に 12mm の余白を描き込む。印刷するときは `@page { margin: 0 }` にして、絵を用紙いっぱいに置く |

## 4. 図の見やすさ（10/14 夜の PDF を見た気づき）

| どこ | 今 | 直し方 |
|---|---|---|
| プレートのステップで、端のパーツ（Noun 222 のステップ 11・12） | 図の右はしにかかって、太い黒枠が切れて見える | プレートの図の**まわりに 1 マス分の余白**を足して描く（隣のプレートは塗らない）。端のパーツも枠ごと全部見えるようにする |
| つなぎのステップ（ステップ 9 など） | 40 × 40 の全体図なので、パーツが小さくて薄い | **このステップで置くパーツを囲む範囲に寄せて**描く（まわりに 4 マス、最低 20 × 20 マス）。プレートの継ぎ目の線は今どおり入れる。下に「全体図（継ぎ目をまたぐパーツ）」ではなく「◯◯と◯◯の継ぎ目」と書く |
| ステップの見出し | 「ステップ 12 / 27　左下プレート・イエロー・オレンジ」が箱の幅で折り返し、「ジ」だけ 2 行目に落ちる | 2 行に分ける。1 行目「ステップ 12 / 27」、2 行目「左下プレート・イエロー・オレンジ」。2 行目が長いときは文字を少し小さくして 1 行に収める |

## 5. やらないこと

- ステップの順番・分け方は変えない（`steps.js` は触らない）
- 部品リスト・買い物リストの中身（数・値段）は変えない
- 画面の遊ぶ部分は触らない
