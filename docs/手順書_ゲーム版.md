# naoblock builder 手順書（ゲーム版：回してはめるブロックパズル）

スマホのちーちゃん（実装）へ。MacBook のちーちゃん（検証）が下の「検証チェックリスト」で確かめるので、その前提で作ってください。
なおなおと 2026-10-12 に壁打ちして決めた内容です。決定事項は勝手に変えず、迷ったらなおなおに聞いてください。

※ `docs/手順書.md`（体験版）の**手順1〜4（ドット・色・パーツ割り・組立順）と手順6〜8（完成画面・表記・印刷）はそのまま使う**。この手順書は、そこに「ゲームとしての遊び方」を足して、**体験版の遊ぶ画面（手順5）を置き換える**ものです。「（仮）」と書いた数字は、作ってから遊んで調整します。

## 1. 作るもの

Nouns の 40×40 を、**次に出てくるブロックを動かして回して、正しい場所にはめていくパズルゲーム**。プレート 1 枚を 1 ステージとして、ステージごとにクリアしていく。完成すると、紙の組立図（体験版の手順8）を印刷して、ブロックをそろえれば実物も組み立てられる。子ども向けの知育玩具として遊べるようにする。

## 2. 決定事項（変えない）

| 項目 | 決定 |
|---|---|
| 遊びの中心 | **ハイブリッド**。前半のステージは落ちてこないパズル型、後半のステージはテトリスのように落ちてくる |
| 正解の場所 | **組立図どおりの 1 か所だけ**（位置と向きが合ったときだけはまる）。だから完成形は必ず紙の組立図と同じになる |
| ステージ | **プレート 1 枚＝1 ステージ**（左上→右上→左下→右下）。最後に継ぎ目をまたぐパーツの「つなぎ」ステージ |
| モード | 最初に選ぶ。**れんしゅう**（時間制限なし）と **タイムアタック**（ステージごとに制限時間、時間切れはそのステージをやり直し、ランキングあり） |
| 次のブロック | 今持っているブロックと、**次の 1 個だけ**を見せる |
| 操作 | **画面のコントローラー**（十字キー・回転・はめる）＋ PC はキーボード。**盤面のタップも残す**（タップした場所へブロックが飛ぶ。小さい子用） |
| ブロックの形 | 長方形 9 種＋**L 字（単品部品の 1×2L）**＋**組み合わせブロック**（山型など。中身は標準パーツ） |
| 作る場所 | naoblock-builder の中で、**体験版の遊ぶ画面を置き換える**（2 画面を並べて残さない）。kit は使わなくてよいが、操作感は咲耶 GAMES に寄せる |

## 3. ブロック

### 3-1. L 字（1×2L）を足す

- Kawada Base の単品部品「1×2L」：**2×2 から角を 1 つ欠いた、ポッチ 3 つの L 字**。30 個入り 220 円。向きは 4 通り
- `src/tiling.js` の形に足す。パーツ割りのルール（全マスちょうど 1 回・同じ色・乱数なし・継ぎ目をまたぐ置き方を優先）はそのまま
- L 字を使う場面（仮）：長方形で埋めると 1×1 が出てしまう角の 3 マス。**1×1 を減らす**のが目的
- `data/parts.json` に 1×2L（30 入・220 円）を足す。部品リスト・買い物リスト・印刷にもそのまま出る
- `tools/check.mjs` の検算（全マスちょうど 1 回など）が L 字でも通ること

### 3-2. 組み合わせブロック（ゲームの中だけ）

- パーツ割りが終わったあとに、**隣り合った同じ色の標準パーツを 2〜3 個まとめて、1 手で置くブロック**にする（山型・大きい L・Z 字・S 字など、回すと形が変わるもの）
- **紙の組立図・部品リスト・買い物リストは、中身の標準パーツのまま**（組み合わせはゲームの見せ方だけ）
- 同じステージの中だけでまとめる（継ぎ目をまたいでまとめない）
- まとめる割合（仮）：ステージのブロックの 3 割くらい。長方形ばかりだと回す楽しさが出ないので、遊んで調整
- まとめ方は乱数を使わない（同じ Noun なら毎回同じ）
- 純粋関数 `src/pieces.js`：パーツ一覧 → ゲームのブロック一覧（各ブロックに中身のパーツの番号）

## 4. 遊び方

### 4-1. ステージの流れ

| ステージ | 中身 | 型 |
|---|---|---|
| 1 | 左上プレート | パズル型（落ちてこない） |
| 2 | 右上プレート | パズル型 |
| 3 | 左下プレート | 落ちてくる |
| 4 | 右下プレート | 落ちてくる |
| 5 | つなぎ（継ぎ目をまたぐパーツ） | 落ちてくる（少し速い） |

- ブロックを出す順番（仮）：ステージの中で**下の行から**（テトリスらしく積み上がって見えるように）。同じ行なら左から
- ステージをクリアしたら「ステージ 2 クリア！ ○秒」を出して次へ

### 4-2. パズル型（ステージ 1・2）

- 持っているブロックは盤面の上に半透明で浮かんでいて、十字キーで 1 マスずつ動かす。回転ボタンで 90 度回す
- 「はめる」ボタン → 位置と向きが正解なら「カチッ」とはまって次のブロックへ。違えば軽く揺れて戻る（間違いは数えない）
- 正解の場所に重なっているときは、ブロックの縁が少し光る（「ここで押せばはまる」が分かるように）

### 4-3. 落ちてくる型（ステージ 3〜5）

- ブロックがステージの上の端から、一定の間隔で 1 マスずつ下へ落ちる（仮：0.8 秒に 1 マス。ステージ 5 は 0.6 秒）
- 動かして回して、**正解の位置と向きに重なった瞬間に自動ではまる**。下ボタンで速く落とせる
- ステージの下の端まで落ちても はまらなかったら、上からやり直し（間違いは数えないが、時間は進む）
- 真上から見ている盤面なので、落ちてくるブロックは置いたブロックの上を通り抜けてよい（手に持って運んでいるイメージ）

### 4-4. モード

| | れんしゅう | タイムアタック |
|---|---|---|
| 制限時間 | なし | ステージごと（仮：ブロック数 × 10 秒） |
| 時間切れ | — | そのステージを最初からやり直し |
| 落ちる速さ | タイムアタックの半分 | 4-3 のとおり |
| ヒント | 5 秒迷ったら正解の場所が光る | ヒントボタン（押すと光る。1 回 +3 秒） |
| 記録 | かかった時間だけ | 合計タイムでランキング（naoblock 専用・この端末だけ。Noun の番号ごと、ガイドあり／なしで別々に上位 5 件） |

- 途中保存（体験版と同じく localStorage、Noun の番号とモードごと）はれんしゅうだけ。タイムアタックはステージの途中で閉じたら、そのステージの最初から

### 4-5. 操作

| 操作 | 画面のコントローラー | キーボード | タップ |
|---|---|---|---|
| 動かす | 十字キー | 矢印キー | 盤面のマスをタップ → ブロックがそこへ飛ぶ |
| 回す | 回転ボタン | Z / X | 持っているブロックをタップ |
| はめる（パズル型） | はめるボタン | スペース | 飛んだ先が正解なら そのままはまる |
| 速く落とす（落ちてくる型） | 下 | ↓ | — |

- コントローラーは画面の下に固定。盤面はコントローラーにかからない大きさに収める（スマホ縦で 40×40 が全部見える。拡大はしない）
- 盤面には、今のステージのプレートだけ明るく、ほかのプレートは暗く見せる
- 次のブロックの見本は右上。体験版の「完成図の小窓」は残す（タップで大きく表示・完成図／元絵の切り替えもそのまま）

### 4-6. ガイド（あり／なし）

- モードをえらぶ画面に「ガイド あり / なし」のスイッチ。前回の選択を覚えておく（はじめは「なし」）
- ガイドあり：まだ置いていないブロックを全部、盤面に**薄い色＋ブロックの外形の線**で出す（パズルの台紙のように、置くブロックの形がわかる）。置いたブロックはその上に乗る
- れんしゅう・タイムアタックのどちらでも選べる
- タイムアタックのランキングと途中保存は、ガイドあり／なしで別々。れんしゅうの途中保存は共通
- 完成画面・シェアの文面・「続きから」の文言に「ガイドあり」を出す（例：「Noun 11 をナオブロックで組み立てた！ タイムアタック（ガイドあり） 3分12秒 #naoblock #Nouns」）

## 7. 検証チェックリスト（MacBook のちーちゃんがやる）

- [ ] L 字を入れても、全マスがちょうど 1 回ずつ覆われている／空きマスに置いていない／1 つのパーツの中が同じ色（Noun 0・11・1000 など）
- [ ] L 字を入れて 1×1 の個数が減っている（入れる前と比べる）
- [ ] 組み合わせブロック：中身のパーツが全部ちょうど 1 回ずつどれかのブロックに入っている／同じ色だけ／ステージをまたいでいない／2 回作って同じ
- [ ] 組み合わせても、部品リスト・買い物リスト・印刷は標準パーツのまま（数字が変わらない）
- [ ] パズル型：正解の位置と向きでだけはまる。違う場所・違う向きでは揺れて戻る
- [ ] 落ちてくる型：正解に重なった瞬間にはまる。下の端まで落ちたら上からやり直し
- [ ] 回転：L 字・組み合わせブロックは 4 通り、長方形は 2 通り、正方形と 1×1 は回しても見た目が変わらない
- [ ] タップ操作だけでも最後まで完成できる
- [ ] タイムアタック：時間切れでそのステージだけやり直し、ヒントで +3 秒、合計タイムが正しい
- [ ] れんしゅう：途中で閉じて開き直すと続きから再開できる
- [ ] ガイドあり：まだ置いていないブロックの形が薄く出る。置くとその上にはまる。タイムアタックのランキングがガイドあり／なしで別々
- [ ] 完成形が紙の組立図（印刷）と同じ
- [ ] スマホ縦で 40×40 とコントローラーが全部見える。PC はキーボードで遊べる
- [ ] コンソールのエラーが 0

## 8. まだ決めていないこと（なおなおに確認）

- 「（仮）」の数字（制限時間・落ちる速さ・組み合わせの割合）は、プロトを遊んでから決める
- アプリの名前（例：ナオブロック パズル）
- プレートの色・ブロックの実際の色（いまはどちらも仮の RGB）

### 決まったこと

- 組み合わせブロックは**同じ色だけ**でまとめる（色は混ぜない。PR #6 のとき）
- タイムアタックのランキングは **naoblock 専用・この端末だけ**（咲耶 GAMES の共通ランキングには乗せない。PR #10 のとき）
- 制限時間は「ブロック数 × 10 秒」、ヒントは 1 回 +3 秒に変えた（PR #11。まだ仮）
- ガイドあり／なしを足した（4-6。PR #12）
