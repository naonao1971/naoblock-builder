## 1. 作るもの

PR は 1 本。版の番号は、今までどおりその PR の番号にする。

| # | 何を | ひとことで |
|---|---|---|
| A | Nouns タブを開いたとき | **最新の 30 体**を、絵のカードで並べる |
| B | 範囲検索 | **開始番号を入れると、そこから 30 体**。「◀ 前の 30 体／次の 30 体 ▶」で送れる |

今の「Noun の番号を入れて遊ぶ」欄（`#noun-form`）は**そのまま残す**。

## 2. 絵は前もって用意しない（その場で描く）

| 項目 | 決定 |
|---|---|
| 考え方 | 画像ファイルは作らない・置かない。ゲームと同じく、seed（パーツ番号 5 つ）＋ image-data（全パーツの絵、圧縮で約 32KB）からブラウザで描く |
| seed | subgraph（`src/nouns.js` の `SUBGRAPH_URL`）に **30 体分をまとめて 1 回**で問い合わせる：`nouns(first: 30, where: { id_in: ["100", "101", …] }) { id seed { background body accessory head glasses } }` |
| image-data | `fetchImageData()` を 1 回だけ読み、使い回す（モジュールの中で Promise を覚えておく）。ゲームを始めたときも同じものを使う |
| 最新の番号 | `auctions(first: 1, orderBy: startTime, orderDirection: desc) { id }`。**`nouns` を `orderBy: id` で並べてはダメ**（id が文字なので 999 が最大になる） |
| 描き方 | `decodeNoun(seed, imageData)` で 32×32 を出し、`<canvas>` に背景色（`imageData.bgcolors[seed.background]`）＋絵を描く。カードの見た目は今の `.picture-card`（88px・`image-rendering: pixelated`）に合わせる |
| 足す関数 | `src/nouns.js` に `fetchSeeds(ids)`（まとめて取る）と `fetchLatestId()`。今の `fetchSeed` は残す |
| 一度見た範囲 | 同じページの中では覚えておき、前後に送ってもどってきたときは問い合わせない |

## 3. A：最初の 30 体

| 項目 | 決定 |
|---|---|
| 並べる Noun | **最新の 30 体**（今オークション中の Noun ＝最新の番号から、その 29 番前まで）。毎日 1 体増えて自動で入れ替わる |
| 並べ方 | 番号の小さい順（左上が最新−29、右下が最新）。範囲検索と同じ並び（仮） |
| カード | 絵＋「Noun 2046」。押すと `?noun=2046`（今の番号入力と同じところへ行く） |
| 見出し | 「Noun 2017〜2046」のように、今見ている範囲を出す |
| 読み込み中 | カードの場所に「読み込み中…」 |
| 失敗したとき | 「Noun の一覧を読み込めませんでした」＋「もう一度」ボタン。番号を入れて遊ぶ欄はふつうに使える |

## 4. B：範囲検索

| 項目 | 決定 |
|---|---|
| 入れるもの | 開始番号 1 つ（「◯ 番から 30 体を見る」）。数字のキーボードを出す |
| 出すもの | 開始番号〜開始番号＋29 の 30 体 |
| 送り | 「◀ 前の 30 体」「次の 30 体 ▶」。0 番より前・最新より後はない（はみ出すときは端で止める。例：最新が 2046 で 2030 を入れたら 2017〜2046） |
| 端 | 0 番からのときは ◀ を押せない。最新までのときは ▶ を押せない |
| 番号入力（遊ぶ）との区別 | 遊ぶ欄は「Noun の番号 → 遊ぶ」のまま。見る欄は一覧の上に置き、ボタンの言葉で区別する（「遊ぶ」と「見る」） |
| 押しやすさ | ◀ ▶ と見るボタンは 48px 以上（子どもの指でも押せるように） |

## 4.5 追加（2026-10-15、PR #33 の検証で判明）：新しいパーツの Noun は noun.pics から描く

PR #33 に続けて足す。なおなおと決定済み。

| 項目 | 決定 |
|---|---|
| 問題 | image-data（`@nouns/assets@0.10.0`。npm の最新・公式 GitHub も同じ）は bodies 30・accessories 143・heads 254・glasses 23 まで。**あとからチェーン上に足されたパーツを使う Noun が 68 体**（最初は 1405。最新 30 体の中にも 2046 など 3 体）。`decodeNoun` が `undefined.data` で落ちる |
| 今の被害 | 本番 v31 でも `?noun=2046`・`?noun=1405` は「読み込めませんでした」でゲームが始まらない。PR #33 の一覧は、1 体でも落ちると一覧ごと止まる |
| 直し方 | **seed のパーツが image-data に全部あるときは今までどおり**。1 つでもないときだけ、`https://noun.pics/<番号>.svg` を読んで 32×32 にする |
| noun.pics | チェーン上の絵をそのまま返す SVG。`access-control-allow-origin: *`。320×320、1 マス＝10px |
| SVG の読み方 | 最初の `<rect width="100%" …>` の `fill` が背景色。ほかの `<rect width x y fill>` は横に並んだマス（`width / 10` マス分）。書いてある順に塗る（後のものが上）。塗られないマスは null（透明） |
| 確かめ済み | Noun 0・11・222・1000・1404 で、noun.pics の SVG を上の読み方で読んだ 32×32 と背景色が `decodeNoun` と**全マス同じ**（MacBook で確認） |
| 置き場所 | `src/nouns.js` に `hasAllParts(seed, imageData)` と `fetchNounSvgGrid(id)`（戻り値 `{ grid, bgHex }`）。SVG の文字から 32×32 にする部分は純粋関数（`parseNounSvg(svg)`）にして、`tools/check.mjs` で確かめる |
| 使うところ | ①ゲーム：`nounSubject` の `load()`。②一覧のカード。どちらも同じ関数（「seed → 絵」を 1 か所にまとめる） |
| 一覧で 1 体だけ失敗 | **一覧ごと止めない**。そのカードだけ「Noun 2046」＋絵の代わりに「？」を出し、押せばゲームへ（ゲーム側でもう一度読む） |
| noun.pics が止まっているとき | ゲームは今と同じ「読み込めませんでした」＋「もう一度」。古いパーツだけの Noun（1979 体）は noun.pics に関係なく遊べる |
| 問い合わせの数 | 新しいパーツの Noun の分だけ、SVG を 1 体 1 回。一覧の 30 体なら多くて数回。一度読んだ絵は覚えておく |

## 5. やらないこと

- 画像ファイルを用意する・サーバーに置く
- 30 体より多く一度に出す
- Nouns 以外のタブ（忍者・CNP など）を変える

## 6. 検証チェックリスト（MacBook のちーちゃん）

1. Nouns タブを開くと、最新の Noun を含む 30 体の絵が並ぶ（最新の番号は Nouns のオークションと同じ）
2. 30 体の絵が、それぞれ `?noun=番号` で開いたときのゲームの元絵と同じ（3 体ほど見比べる）
3. 一覧を出すときの subgraph への問い合わせは「最新の番号」1 回＋「30 体の seed」1 回だけ。image-data は 1 回だけ読む
4. カードを押すと、その Noun のゲームが始まる
5. 開始番号 100 → Noun 100〜129。▶ で 130〜159、◀ で 100〜129 にもどる（もどったときは問い合わせない）
6. 開始番号 0 → ◀ が押せない。最新に近い番号 → 最新で止まり、▶ が押せない
7. 数字以外・空のときは何もしない（エラーを出さない）
8. 通信を切って開くと、失敗の案内と「もう一度」が出る。つないで「もう一度」で並ぶ
9. 今の「Noun の番号を入れて遊ぶ」欄がそのまま使える
10. スマホ縦 390×844 で、カードがはみ出さず、◀ ▶ が 48px 以上
11. 忍者・CNP などほかのタブが今までどおり
12. コンソールにエラーが出ていない
13. （4.5）最新 30 体が全部並ぶ（2046 などの新しいパーツの Noun も絵が出る）
14. （4.5）`?noun=2046`・`?noun=1405` でゲームが始まり、元絵が noun.pics の絵と同じ
15. （4.5）古いパーツだけの Noun（0・11・1000 など）は noun.pics を読みに行かない
16. （4.5）noun.pics を止めると：一覧はほかの 27 体が並び、新しいパーツの 3 体は「？」のカード。ゲームは「読み込めませんでした」
