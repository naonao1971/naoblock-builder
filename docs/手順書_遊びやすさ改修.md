※ **PR ができたら、マージの前に MacBook のちーちゃんの検証を通す**（なおなおと約束済み）。

## 1. 作るもの

PR は 1 本（v30）。改修は 4 つ。

| # | 何を | ひとことで |
|---|---|---|
| A | れんしゅうの黄色い枠 | 待たずに、最初から出す |
| B | X シェア | 完成図の画像を付けてシェアする。「画像を保存」ボタンはなくす |
| C | 🔊・？・💡 のボタン | コントローラーから外して、右上の ⏸ メニューに入れる |

## 2. A：れんしゅうの黄色い枠を待たずに出す

| 項目 | 決定 |
|---|---|
| 今 | れんしゅうは `HINT_MS = 5000`（`src/main.js`）。5 秒迷うと正解の場所が黄色く光る。待つのがストレス |
| これから | **れんしゅうは、ブロックが出た瞬間から黄色い枠を出す**（待ち 0）。次のブロックに替わっても、すぐ出す |
| タイムアタック | 今のまま。ヒントは自分で出す（+3 秒）。出す場所は ⏸ メニューの中（4 章） |
| ガイドあり／なし | **れんしゅうにも残す**。ガイド＝まだ置いていないブロックの形を薄く出す、黄色い枠＝今持っているブロックの置き場所。役目が別 |
| 遊び方の説明 | 「5 秒迷うと光る」と書いてあるところは、「れんしゅうは置く場所が黄色く光る」に直す |

## 3. B：X シェアに完成図を付ける

| 項目 | 決定 |
|---|---|
| 今 | 「X にシェア」（`#share-x`）は X の投稿画面（intent URL）を開くだけで、画像が付かない。画像は「画像を保存」（`#save-image`）で別に保存して、手で添付している |
| これから | **咲耶ゲームと同じ作り**。`~/dev/sakuya-kit/src/share.js` の `shareResult` を手本にする（ビルダーは kit を読み込んでいないので、同じ動きを `src/finish.js` に書く） |
| スマホ（共有に対応） | `navigator.canShare({ files })` が true なら `navigator.share({ text, files: [完成図の PNG] })`。iPhone の共有シートで X を選ぶと、画像と文章が付いた投稿画面になる |
| PC など（非対応） | 完成図の PNG を自動で保存 → X の投稿画面を開く → 「画像を保存しました。投稿画面に添付してください」と出す |
| 共有シートを閉じた | `AbortError` はエラーにしない（何も出さない） |
| 画像 | 今「画像を保存」で出している完成図（`#finish-canvas`）と同じもの。ファイル名も今と同じ |
| URL | 共有シートでは URL が落ちることがあるので、**文章の最後に URL を入れる**（`subject.url(...)`）。intent URL のときに二重にならないようにする |
| ボタン | 「画像を保存」は**なくす**。シェアのボタンは 1 つで、名前は **「X にシェア」のまま**。`<a>` ではなく `<button>` にする |

## 4. C・D：右上の ⏸ メニュー

### 4-1. ボタン

| 項目 | 決定 |
|---|---|
| 今 | `footer.controller` の `.tools`（十字キーと「回す・はめる」の間）に 🔊 `#mute`・？ `#help-open`・💡 `#hint`。親指の通り道なので、まちがえて押しやすい |
| これから | `.tools` は**なくす**。遊ぶ画面の**右上（`header.hud-top` の中）に ⏸ ボタンを 1 つだけ**置く。押しやすい大きさ（44px 以上）にする |
| ヘッダーの「naoblock」 | 遊ぶ画面では**リンクをやめて、ただの文字**にする（⏹ やめると役目がかぶるので） |
| キーボード | Esc で ⏸ メニューを開く／閉じる（PC 用） |

### 4-2. メニュー（モーダル）

⏸ を押すと、ゲームが止まってメニューが開く。上から次の順で並べる。

| ボタン | 動き |
|---|---|
| ▶ つづける | 閉じて、続きから遊ぶ |
| ↺ やり直す | 「このステージを最初からやり直しますか？」と確認 → はい なら、**今のステージの最初から**（`game.restartStage()`） |
| ⏹ やめる | スタート画面にもどる。途中までの記録は今どおり保存し、次に同じ絵を選ぶと「続きから」遊べる |
| 💡 ヒント（+3 秒） | **タイムアタックのときだけ出す**。押すとメニューを閉じて、正解の場所を光らせる。+3 秒は今と同じ（もう光っているときは数えない） |
| 🔊 音 | オン／オフ。今の `#mute` と同じ動き（表示も 🔊／🔇 で切り替える） |
| ？ 遊び方 | 今の遊び方の画面（`#help`）を開く。閉じたら ⏸ メニューにもどる |

### 4-3. 止まっている間

| 項目 | 決定 |
|---|---|
| タイマー | ⏸ メニューを開いている間は**止める**（`clock.pause()`）。閉じたら動かす |
| 落下 | 止める（今の `anyModalOpen()` に ⏸ メニューを足せば、時計の針の処理は止まる） |
| 盤面の操作 | メニューの外をタップしても、ブロックは動かない |
| アプリを裏に回した | 今と同じ（`visibilitychange` で止まる） |

### 4-4. やり直しとタイムアタック（仮）

今のアプリは、タイムアタックで時間切れになると、**♥ が 1 つ減って、タイムはそのステージの最初にもどる**（`retryStage`。やり直した分の時間は合計に入れない）。
⏸ の「やり直す」もこれと**同じ扱い**にする（仮）：

- タイムアタック：♥ が 1 つ減って、タイムはステージの最初にもどる（`retryStage` を使う）。♥ が 1 つしかないときは「やり直す」を押せないようにして、「♥ が足りません」と出す
- れんしゅう：何も減らない。ステージの最初からにするだけ

※ ♥ を減らさずにタイムだけもどせると、失敗したステージだけ何度もやり直してランキングのタイムを良くできてしまうため。なおなおに確認してから決める。

## 5. やらないこと

- パーツ割り・ステージ・落下の速さ・♥ の数は変えない
- 組立図・PDF・印刷は触らない
- スタート画面・完成画面のほかのボタン（PDF で保存・プリンターで印刷・もう一度）は変えない

## 6. 検証チェックリスト（MacBook のちーちゃん）

1. れんしゅう（ガイドあり・なしの両方）：ブロックが出た瞬間から黄色い枠が出る。はめて次のブロックになっても、すぐ出る
2. タイムアタック：最初は黄色い枠が出ない。⏸ → 💡 で光り、タイムが +3 秒。もう光っているときに押しても増えない
3. れんしゅうの ⏸ メニューには 💡 が出ない
4. コントローラーに 🔊・？・💡 がない。右上に ⏸ がある（スマホ縦 390×844 で、十字キー・回す・はめるから離れている）
5. ⏸ を開いている間、タイマーが進まない・ブロックが落ちない。閉じると続きから動く
6. ↺ やり直す：確認が出る → はい で、今のステージの最初にもどる（前のステージまでに置いたブロックは残る）。タイムアタックは ♥ が 1 つ減ってタイムがステージの最初にもどる。♥ が 1 つのときは押せない
7. ⏹ やめる：スタート画面にもどる。同じ絵・同じモードを選ぶと「続きから」が出る
8. 🔊：音が消える／出る。ページを読み込み直しても覚えている（今と同じ）
9. ？：遊び方が開いて、閉じると ⏸ メニューにもどる
10. Esc で ⏸ メニューが開く／閉じる
11. 遊ぶ画面の「naoblock」がリンクでなくなっている
12. 完成画面：「画像を保存」がない。「X にシェア」を押すと、PC（Chrome）では PNG が保存されて X の投稿画面が開き、案内が出る。文章の最後に URL が 1 つだけ入っている
13. **iPhone（なおなお）**：「X にシェア」→ 共有シート → X で、完成図と文章（URL 入り）が付いた投稿画面になる。共有シートを閉じてもエラーが出ない
14. コンソールにエラーが出ていない
